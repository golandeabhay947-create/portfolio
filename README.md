# Abhay Golande Portfolio

A responsive React + Vite personal portfolio, based only on the supplied resume.

## Run locally

1. Install Node.js 20 or later.
2. Run `npm install`.
3. Run `npm run dev` and open the URL Vite displays.

## Production build

Run `npm run build`. The deployable static site is created in `dist/`.

## Deploy

### Vercel

Import the repository, leave the framework preset as **Vite**, and deploy. Use `npm run build` with `dist` as the output directory if Vercel does not auto-detect it.

### Netlify

Import the repository and use build command `npm run build` and publish directory `dist`.

## Contact form

The form opens a pre-filled email draft addressed to the resume-supported contact email. No third-party form service or invented endpoint is used.

## Resume

The downloadable source resume is located at `public/Abhay_Golande_Resume_AI_Engineer.docx`.
